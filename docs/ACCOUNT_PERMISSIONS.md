## 行级数据权限 ≠ 页面权限

页面权限缺失会显式报 `1004`；但还存在**行级数据权限**：查询成功（不报错）却只返回授权范围内的
数据——`rows [区域]` 只回授权区域、显式筛选无权限区域返回**空表头**（2026-09-03 实测：
2024071793 查迪桑特日报，区域仅返回华东区 1 行，筛「迪桑特-华北区」返回空表头）。
这种**静默缩数据**极易被当成全国数据交付。

处置：报告采集前先 `rows [区域]` 查一次全量核对区域覆盖；区域数明显少于预期 → 换全国权限
账号，或在报告中明确注明数据范围（见文头「报告必须注明取数账号」）。

## 遇 1004 的处置

1. 查本表换有权限的账号；
2. 跑 `python scripts/collect_user_pages.py <工号>` 确认该账号可见页面（详见
   [PAGE_DISCOVERY.md](PAGE_DISCOVERY.md)）；
3. 都不行 → 联系 BI 管理员为账号开对应报表权限。

## 维护

- 新增观察（无论成功还是 1004）：由 agent 在 `submit_feedback` 的 `issue`/`skill_call`
  里带上工号+报表+结果，维护者核阅后更新本表；
- 同一账号权限可能随时间变化（如 2024100967 同日先后出现 ✅ 与 ❌1004），更新时保留观察日期。
