# 报表指引：零售运营分析-日报-迪桑特（retail_daily_descente）

DESCENTE/迪桑特品牌的零售日报。45 维度 × 73 度量，最细到「店 × 日」颗粒。
适用：迪桑特流水量、目标达成、折扣、客单价、同店、进店客流等分析。
指标含义查 `metrics-glossary.md`（Grep，勿整读）。字段名以下方维度/度量清单为准（逐字一致），fdId 由 MCP 服务端按名解析。

## 维度（45，按分类）

- **时间（6）**：日历日期、日历年份、日历季度、日历月份、日历周数、周几
- **组织（7）**：零售经理、办事处、省份、区域、区域编码、城市等级、城市_映射
- **店铺（10）**：店铺编码、店铺名称、店铺类型明细、门店性质、门店类型、经营类型、店型、店铺楼层、店铺等级编码、门店销售面积
- **商场（3）**：商场体系、商场代码、商场名称
- **品牌（5）**：品牌大区、渠道品牌、商品品牌、财务所属品牌、品牌终端形象
- **同店/有效店（6）**：同店类型、是否同店、月同店标识、有效店标识、有效店标识同期、集合店属性
- **标签（3）**：顶特高、灯塔店、重点店铺
- **开店/改造（5）**：第一次开业日期、闭店日期、最新改造类型、最近一次改造开始日期、最近一次改造结束日期

## 度量（73，按分类）

- **流水/目标（9）**：流水、流水同期、流水同比、零售流水目标、零售达成、同店流水、同店流水同期、同店流水同比、有效流水
- **预算（2）**：预算流水目标、预算达成
- **销售（6）**：销售吊牌金额、销售吊牌金额同期、销售吊牌金额同比、销售数量、销售数量同期、销售数量同比
- **小票（5）**：小票数、小票数同期、小票数同比、单件小票数、单件小票数同期
- **价格/比率（12）**：客单价、客单价同期、客单价同比、件单价、件单价同期、件单价同比、平均牌价、平均牌价同期、平均牌价同比、折扣、折扣同期、折扣同比
- **连带/单件（6）**：连带率、连带率同期、连带率同比_1、单件占比、单件占比同期、单件占比同比
- **同店销售/小票（9）**：同店销售吊牌金额、同店销售吊牌金额同期、同店销售吊牌金额同比、同店销售数量、同店销售数量同期、同店销售数量同比、同店小票数、同店小票数同期、同店小票数同比
- **客流（24）**：店外客流、店外客流同期、店外客流同比、进店客流、进店客流同期、进店客流同比、进店率、进店率同期、进店率同比、日均店外客流、日均店外客流同期、日均店外客流同比、日均进店客流、日均进店客流同期、日均进店客流同比、成交率、成交率同期、成交率同比、进店率计算店外客流、进店率计算进店客流、客流小票数、客流小票数同期、客流有效天数（店+天）、客流有效天数同期（店+天）

## 筛选字段（仅这 3 个有选择器映射，其它字段做筛选会 None.get）

**⚠ 必须双筛**：`渠道品牌=DESCENTE` **和** `商品品牌=迪桑特` 要同时加。只筛渠道品牌会混入
迪桑特-大货/高尔夫/BLANC/儿童等子品牌，流水虚高约一倍（2026-08-11~17 实测：3.11亿 vs 1.56亿）。

| 字段 | 常用值 |
|---|---|
| 渠道品牌 | DESCENTE |
| 商品品牌 | 迪桑特（精确匹配，不含「迪桑特-大货」等子品牌） |
| 区域 | **必须带前缀**：迪桑特-华东区、迪桑特-华北区、迪桑特-东北区、迪桑特-华南区、迪桑特-西区、迪桑特-总部、迪桑特-港澳、迪桑特-电商（用「华东」会返回空） |

## 动态参数（固定 2 个，YYYY-MM-DD）

| 参数名 | 说明 |
|---|---|
| 开始日期-户外-R02 | 查询起始日 |
| 结束日期-户外-R02 | 查询截止日 |

## 模板格式与示例

```yaml
report: retail_daily_descente
rows: [渠道品牌, 店铺名称]          # 维度
metrics: [零售流水目标, 零售达成, 流水, 流水同比, 客单价, 折扣]   # 度量
filters:
  - { name: 渠道品牌, values: [DESCENTE] }
  - { name: 商品品牌, values: [迪桑特] }
dynamic_params:
  开始日期-户外-R02: "2026-08-01"
  结束日期-户外-R02: "2026-08-07"
```

执行：调用 MCP 工具 `export_report`，把上面 YAML 作为 `template_yaml` 字符串传入（见 SKILL.md）。

## 常用配方

- **店铺周流水达成**：rows `[店铺名称]`，metrics `[零售流水目标, 零售达成, 流水, 流水同比]`，日期取周一~周日
- **按省汇总月度折扣/客单价**：rows `[省份]`，metrics `[流水, 折扣, 客单价, 连带率]`，日期取整月
- **同店表现**：rows `[店铺名称]`，filters 加 `是否同店: [是]`（值以枚举为准），metrics `[同店流水, 同店流水同比]`

## 注意

- **办事处有空值**：空白办事处（显示为 `" "`）承接了相当大的流水（实测单周 2771 万、第二大，对应电商/POPUP 渠道）。按办事处汇总时**保留该行并标注「未分配/电商」**，不能当脏数据丢弃
- BI 无「店效」字段：按 `流水 ÷ 有流水的门店数` 自行计算（门店数可用 rows `[店铺名称]` 数非空流水行得到）
- 导出 CSV 恒为全量结果集：模板里的 `limit`/`offset` 只影响 BI 页面表格显示，对导出无效，可不写
- 维度加得越多行数越多（笛卡尔展开），按需选维度
- 拿不准字段名：以本页维度/度量清单为准，字段名需逐字一致
