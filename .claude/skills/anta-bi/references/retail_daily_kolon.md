# 报表指引：零售运营分析-日报-KOLON（retail_daily_kolon）

KOLON/可隆品牌的零售日报。35 维度 × 101 度量，最细到「店 × 日」颗粒。
特色：试衣指标全（18 个，⚠ 当前导出失败，见「已知缺陷」）、挑战目标、店效分级/渠道分级维度。
指标含义查 `metrics-glossary.md`（Grep，勿整读）。字段名以下方维度/度量清单为准（逐字一致），fdId 由 MCP 服务端按名解析。

## 维度（35，按分类）

- **时间（5）**：日历日期、日历年份、日历季度、日历月份、日历周数
- **组织（8）**：销售主管/经理、办事处、办事处编码、省份、区域、区域编码、城市等级、城市_映射
- **店铺（11）**：店铺编码、店铺名称、店铺类型明细、门店性质、门店类型、经营类型、店铺分级、店铺分级编码、渠道分级、店效分级、集合店属性
- **商场（3）**：商场体系、商场代码、商场名称
- **品牌（2）**：品牌大区、渠道品牌
- **同店/有效店（5）**：同店类型、是否同店、月同店标识、有效店标识、有效店标识同期
- **开店（1）**：第一次开业日期

## 度量（101，按分类）

- **流水/目标（9）**：流水、流水同期、流水同比、零售流水目标、零售达成、同店流水、同店流水同期、同店流水同比、有效流水（⚠ 有效流水实测静默丢列；流水同比正常）
- **预算/挑战（4）**：预算流水目标、预算达成、挑战目标、挑战达成
- **销售（6）**：销售吊牌金额、销售吊牌金额同期、销售吊牌金额同比、销售数量、销售数量同期、销售数量同比
- **小票（5）**：小票数、小票数同期、小票数同比、单件小票数、单件小票数同期
- **价格/比率（18）**：客单价、客单价同期、客单价同比、件单价、件单价同期、件单价同比、平均牌价、平均牌价同期、平均牌价同比、折扣、折扣同期、折扣同比、连带率、连带率同期、连带率同比、单件占比、单件占比同期、单件占比同比（⚠ 各「同比」静默丢列，连带率同比导出失败）
- **同店销售/价格（21）**：同店销售吊牌金额、同店销售吊牌金额同期、同店销售吊牌金额同比、同店销售数量、同店销售数量同期、同店销售数量同比、同店小票数、同店小票数同期、同店小票数同比（以上同比可正常导出）、同店折扣、同店折扣同期、同店连带率、同店连带率同期、同店客单价、同店客单价同期、同店件单价、同店件单价同期（⚠ 同店折扣同比、同店连带率同比、同店客单价同比、同店件单价同比这 4 个为派生指标会静默丢列，见「已知缺陷」）
- **客流（19）**：店外客流、店外客流同期、店外客流同比、进店客流、进店客流同期、进店客流同比、进店率、进店率同期、进店率同比、日均进店客流、日均进店客流同期、日均进店客流同比、成交率、成交率同期、成交率同比、客流小票数、客流小票数同期、客流有效天数（店+天）、客流有效天数同期（店+天）（⚠ 实测静默丢列，当前不可用）
- **试衣（18）**：试衣件数(不去重)、试衣件数(货号去重)、试衣件数(人次+货号去重)、试衣人次、人次试衣时长、人均试衣时长、人均试衣件数、人均试衣货号数量、试衣间数量、占用试衣间平均试衣时长、占用试衣间平均试衣人次、试衣率、试衣成交件数、非试衣成交件数、正向销售数量、试衣成交率、试衣商品成交占比、非试衣商品成交占比（⚠ 实测导出失败，当前不可用）
- **标识（1）**：有效店标识（同时也在维度区，做度量时返回汇总标识值）

## 已知缺陷（实测 2026-08-19，仅 KOLON 卡片；DESCENTE 同类指标正常）

**根因**（HAR 元数据分析）：① 卡片级派生指标——101 个度量中恰好 11 个缺 `level:"dataset"` 属性、formula 引用其它计算指标（"计算指标的计算指标"），CSV 导出引擎不物化这类字段；② 跨数据集指标——客流/试衣物理上在别的数据集，页面图表能跨集展示，导出任务只跑主数据集（df905）。**与字段名无关**（名字错会在导出前报「字段未找到」）。

| 症状 | 涉及指标 | 处置 |
|---|---|---|
| **静默丢列**（不报错，CSV 里整列消失） | 缺 level 的 11 个派生指标：**客单价同比、件单价同比、平均牌价同比、折扣同比、单件占比同比、连带率同比、同店折扣同比、同店连带率同比、同店客单价同比、同店件单价同比、有效流水**（前 7+有效流水 已实测确认，后 4 个由元数据判定）；跨数据集的客流类：进店客流、成交率等 | **不可用**。同比改查「本期 + 同期」两个原始值自行计算；客流暂无替代 |
| **导出任务失败**（status=FAILED） | 连带率同比；试衣类全部（试衣率、试衣人次等，formula 跨数据集） | **不可用**。移出 metrics；混查时逐个减指标定位坏指标 |

**每次导出后必须核对 CSV 表头与请求的 metrics 一致**——缺列就是被静默丢弃，结果不是缺数据而是该指标根本没导出。
（无固定指标数量上限：12 个安全指标一次导出成功；失败均由具体坏指标引起。注意：**流水同比、销售吊牌金额同比、销售数量同比、小票数同比、同店销售吊牌金额/销售数量/小票数同比**等有 level 属性，可正常导出。）

| 字段 | 常用值 | sourceCdId 场景 |

## 动态参数（固定 2 个，YYYY-MM-DD）

| 参数名 | 说明 |
|---|---|
| 开始日期-户外-R02 | 查询起始日 |
| 结束日期-户外-R02 | 查询截止日 |

## 模板格式与示例

```yaml
report: retail_daily_kolon
rows: [日历日期, 店铺名称]
metrics: [流水, 预算流水目标, 零售达成, 流水同比, 试衣率]
filters:
  - { name: 渠道品牌, values: [KOLON] }
dynamic_params:
  开始日期-户外-R02: "2026-08-01"
  结束日期-户外-R02: "2026-08-07"
```

执行：调用 MCP 工具 `export_report`，把上面 YAML 作为 `template_yaml` 字符串传入（见 SKILL.md）。

## 常用配方

- **按日流水走势**：rows `[日历日期]`，metrics `[流水, 流水同期, 流水同比]`
- **店铺月度达成（含挑战）**：rows `[店铺名称, 店效分级]`，metrics `[预算流水目标, 预算达成, 挑战目标, 挑战达成, 流水]`
- **试衣转化分析**：⚠ 试衣/客流指标当前导出失败/丢列（见「已知缺陷」），此配方暂不可用，可先查 `[流水, 客单价, 连带率]` 代替
- **区域店效**：rows `[区域]`，filters 加 `区域: [可隆-华东]`（值以枚举为准）

## 注意

- KOLON 卡片的完整字段目录不在页面元数据里，来自查询抓包（HAR）；选择字段时以本指引清单为准（含其它品牌卡片字段的整页字段池不在此列）
- 同名字段跨数据集（如「区域」「有效店标识」）由脚本按 default_ds_id 自动解析，无需干预
- BI 无「店效」字段：按 `流水 ÷ 有流水的门店数` 自行计算（门店数可用 rows `[店铺名称]` 数非空流水行得到）
- 导出 CSV 恒为全量结果集：模板里的 `limit`/`offset` 只影响 BI 页面表格显示，对导出无效，可不写
- 拿不准字段名：以本页维度/度量清单为准，字段名需逐字一致
