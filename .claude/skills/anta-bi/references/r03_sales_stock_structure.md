# 报表指引：R03-任意时间段销存结构分析（r03_sales_stock_structure）

商品运营分析：销存结构报表，最细到「店仓 × 货号 × 尺码/颜色」颗粒（SKU 级）。79 维度 × 70 度量。
适用：商品结构分析（大类/中类/系列/货号）、库存健康（动销率/库销比/齐码率）、售罄与采购报废、任意自定义时间段及其同期对比。
指标定义见 `test/商品运营分析-指标说明.xlsx`（75 行业务口径，按需查）。字段名需逐字一致，fdId 由 MCP 服务端按名解析。
完整 fdId 清单在项目 `templates/r03_sales_stock_structure.reference.yaml`（Grep 定位，勿整读）。

## 与零售日报的区别

- **商品颗粒**（非店铺日颗粒）：多了货号/款号/商品编码/尺码/颜色/商品名称/商品品牌/大类/中类/小类/系列/子系列/产品年季/配货季/上市日期/是否新品 等商品维度
- **店仓**而非店铺：字段叫 `店仓编码`/`店仓名称`（不是 店铺编码/店铺名称）
- 度量是「销存」口径：流水/销售吊牌额/**销售吊牌额**（注意：此处叫"吊牌额"非日报的"吊牌金额"）、库存/动销/齐码/采购/报废，**无客流/试衣/客单价类**
- **同期可自定义**：`同期开始/结束日期-户外` 两个参数独立指定对比期（不必是去年同期）

## 维度（79，按分类）

- **时间（6）**：日历日期、日历周、日历年周、日历月份、日历季度、日历年份
- **商品（26）**：货号、商品编码、尺码、颜色、款号、商品名称、商品品牌、大类、中类、小类、品类归并、系列、子系列、产品年、产品季、产品年季、配货季、性别、上下装、POP类型、POP时间、IMC类型、IMC时间、业务类型、设计国家、上市日期、上市月、南区/北区/中区上市日期、商品吊牌价格、是否新品、首销日期-货号、首销日期-款号、图片地址、商品层级、商品细分、创新商品、专供款、区分
- **组织（10）**：区域、区域编码、办事处、省份、城市_映射、县区、城市等级、销售主管/经理、渠道品牌、品牌大区
- **店仓（20+）**：店仓编码、店仓名称、店仓标识、店铺类型明细、门店性质、门店类型、店铺等级、经营类型、商场代码/名称/体系、第一次开业日期、关店日期、最新改造类型/开始/结束日期、品牌终端形象、店铺楼层、租赁类型、财务所属品牌、集合店属性、集合店属性明细、是否迪桑特核心城市店

## 度量（70，按分类）

- **销售（16）**：流水、流水同期、流水同比、销售数量、销售数量同期、销售数量同比、销售吊牌额、销售吊牌额同期、销售吊牌额同比、折扣、折扣同期、折扣同比、货通销售流水/数量/吊牌额 及其同期
- **库存基础（6）**：库存数量（+同期/同比）、库存吊牌额（+同期/同比）、实物库存数量、实物库存金额、在途库存数量、在途库存金额
- **SKC 类（14）**：库存SKC数（只对货号去重）、库存SKC数-鞋服（正价折扣 / 正价折扣&只对货号去重）、零售SKC数（只对货号去重 / 正价折扣&只对货号去重 / 无修饰）、进货SKC数（同上 3 变体）、齐码SKC数（正价折扣 / 只对货号去重 / 正价折扣&只对货号去重 / 无修饰）、齐码SKC标记（正价折扣）、低库存SKC数_儿童
- **库存健康（6）**：齐码率、齐码率（正价折扣）、库存均深、库存吊牌均价、动销率、动销率（只对货号去重）、月库销比、月库销比同期
- **期初/采购/报废（12）**：期初库存数量/吊牌额（+同期）、采购入库数量/吊牌金额（+同期/同比）、报废数量/吊牌金额（+同期/同比）

> 括号后缀是**口径修饰**（去重范围/店铺类型过滤），名字必须逐字带全。以 `templates/r03_sales_stock_structure.reference.yaml` 注释清单为准。

## 筛选字段（14 个有选择器映射）

| 字段 | 常用值 |
|---|---|
| 渠道品牌 | DESCENTE / KOLON |
| 商品品牌 | 迪桑特（大货）/ 高尔夫 / 儿童 / BLANC 等子品牌枚举 |
| 品牌大区 | 线上、线下 |
| 区域 / 办事处 | 常规枚举 |
| 店仓编码 / 店仓名称 | 具体店仓 |
| 店铺类型明细 | 正价店、折扣店 等 |
| **货号 / 性别 / 大类 / 中类 / 系列 / 子系列** | 商品筛选（R03 特色） |

## 动态参数（最多 5 个；⚠ 配货季不传即查全部配货季）

| 参数名 | 类型 | 说明 |
|---|---|---|
| 开始日期-户外-R02 | DATE | 本期起始日 |
| 结束日期-户外-R02 | DATE | 本期截止日 |
| 同期开始日期-户外 | DATE | **对比期起始（可自定义，不必是去年同期）** |
| 同期结束日期-户外 | DATE | 对比期截止 |
| 户外_配货季(多选) | STRING | 如 `2026Q3`；传了会只查该配货季商品，**不传查全部** |

## 模板格式与示例

```yaml
report: r03_sales_stock_structure
rows: [中类, 货号]
metrics: [流水, 流水同期, 销售数量, 库存数量, 动销率, 月库销比, 齐码率]
filters:
  - { name: 渠道品牌, values: [DESCENTE] }
  - { name: 商品品牌, values: [迪桑特] }
dynamic_params:
  开始日期-户外-R02: "2026-08-14"
  结束日期-户外-R02: "2026-08-20"
  同期开始日期-户外: "2025-08-13"
  同期结束日期-户外: "2025-08-20"
```

执行：调用 MCP 工具 `export_report`，把上面 YAML 作为 `template_yaml` 字符串传入（见 SKILL.md）。

## 常用配方

- **中类销存结构**：rows `[中类]`，metrics `[流水, 流水同期, 销售数量, 库存数量, 动销率, 月库销比]`
- **货号级售罄/动销**：rows `[货号, 中类]`，metrics `[流水, 销售吊牌额, 库存吊牌额, 动销率, 库存SKC数（只对货号去重）]`
- **店铺 × 大类库存健康**：rows `[店仓名称, 大类]`，metrics `[库存数量, 动销率, 齐码率, 月库销比]`
- **系列同期对比**：rows `[系列]`，metrics `[流水, 流水同期, 库存数量, 库存数量同期]`（同期参数自定义对比期）

## 注意

- **数据量极大**（SKU 级），rows 一定要限定（中类/货号/单店仓），全维度查询导出会非常慢甚至超时
- **配货季参数谨慎传**：只查特定季商品时才传 `户外_配货季(多选)`；排查"查出来是空"时先去掉它
- **字段名口径差异**：本报表是 `销售吊牌额`（日报是 `销售吊牌金额`）、`店仓名称`（日报是 `店铺名称`）、`日历周`（日报是 `日历周数`）
- 导出 CSV 恒为全量结果集：`limit`/`offset` 对导出无效，可不写
- 拿不准字段名：Grep `templates/r03_sales_stock_structure.reference.yaml`
