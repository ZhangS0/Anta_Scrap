# 报表指引：渠道运营分析-月报-KOLON（channel_monthly_kolon）

**可隆(KOLON)品牌**的渠道月报。37 维度 × 250 度量（本库度量最多的报表），最细到「店 × 月」颗粒。
覆盖：销售/同店/客流人次/店数/店效/坪效/面积/改造前后 的 **{月度|年累} × {本期|同期|同比}** 全组合 + 零售/预算目标。
适用：KOLON 月度经营全貌、店效坪效、开关店、客流表现、同比分析。
指标定义见 `test/渠道运营分析-月报-可隆 指标说明.xlsx`。字段名需逐字一致；完整 250 度量清单在项目 `templates/channel_monthly_kolon.reference.yaml`（Grep 定位，勿整读）。

## 与迪桑特月报（channel_monthly_descente）的区别

- **指标全得多**：250 vs 95——多出销售明细类（折扣/连带率/客单价/件单价/平均牌价/单件占比）、同店全系列、**客流人次系列**、目标类（月/年累 零售流水目标 + 预算流水目标）
- **同比字段齐全**：迪桑特月报基本要自己算同比，本报表「月流水同比」「年累流水同比」等直接可查
- **指标名结构**：`{月|年累}{指标}{本期|同期|同比}`，如 `月流水本期`、`年累同店客单价同比`
- **区域枚举**：可隆-东北/华东/华北/华南/华西/品牌/安徽/山西/新疆/西北/香港 等（与迪桑特的 8 区划分不同）
- 同为无动态参数：时间用筛选字段 `日历月份`（YYYY-MM，可多选）

## 维度（37，按分类）

- **时间（2）**：日历月份、日历年份
- **组织（8）**：区域、办事处、省份、城市_映射、区县、零售经理、所属大店长、渠道品牌
- **店铺（19）**：店铺编码、店铺名称、店铺类型明细、店铺级别、渠道级别、店效分级、门店性质、门店类型、经营类型、关店标记、关店日期、第一次开业时间、店龄、形象店龄、改造类型、最新改造开始/结束日期、店铺楼层、是否有效店本期（1是,0否）
- **商场（3）**：商场体系、商场代码、商场名称
- **品牌/其它（5）**：品牌分类、品牌终端形象、财务所属品牌、集合店属性、销售面积_最新

## 度量（250，按命名规律）

**命名公式**：`{月|年累}` + 基础指标 + `{本期|同期|同比}`。基础指标族：

| 基础指标族 | 包含 | 月度 | 年累 |
|---|---|---|---|
| **销售（11）** | 流水、销售数量、销售吊牌金额、小票数、单件小票数、折扣、连带率、客单价、件单价、平均牌价、单件占比 | ✅ | ✅ |
| **同店（8）** | 同店流水、同店销售数量、同店销售吊牌金额、同店小票数、同店折扣、同店连带率、同店客单价、同店件单价 | ✅ | ✅ |
| **客流人次（9）** | 进店客流人次有效天数、客流人次小票数、店外客流人次、进店客流人次、日均进店客流、进店率、成交率（同比仅 5 个） | ✅ | ✅ |
| **店数（5）** | 有效店数、保有店数、新开店数、改造店数、关闭店数 | ✅ | ✅ |
| **店效（4）** | 店效、保有店效、新开店效、改造店效 + 有效流水、有效销售月数 | ✅ | ✅ |
| **面积（6）** | 保有店销售面积、新开店销售面积、改造店销售面积 + 平均面积变体 | ✅ | ✅ |
| **坪效（4）** | 坪效、保有坪效、新开坪效、改造坪效 + 销售面积（坪效） | ✅ | ✅ |
| **目标（4）** | 零售流水目标、预算流水目标 | 月 + 年累 | 年累 |
| **改造前后（7）** | 改造前面积/店效/坪效、改造后面积/店效/坪效、改造坪效提升 | — | ✅ |

## 筛选字段（14 个有选择器映射；⚠ 前两个基础筛选建议必加）

| 字段 | 常用值 |
|---|---|
| 渠道品牌 | KOLON |
| 店铺类型明细 | 正价店、折扣店 |
| **日历月份** | `YYYY-MM`，如 `2026-08`，可多选（**时间控制方式**） |
| 区域 | 可隆-东北/华东/华北/华南/华西/品牌/安徽/山西/新疆/西北/香港 等枚举 + 空白 `" "` |
| 城市_映射 / 店铺编码 / 店铺名称 | 具体值 |
| 门店性质 | 奥莱、机场店、特卖店、百货商场、街铺、购物中心、虚拟/临时/其他 |
| 商场体系 | 万科、万达、中免、佛罗伦萨 等 |
| **是否有效店本期（1是,0否）/ 是否保有店 / 是否新开店 / 是否改造店 / 是否撤消店** | 值为 `"1"`/`"0"`（注意状态筛选字段名带括号说明） |

## 模板格式与示例

```yaml
report: channel_monthly_kolon
rows: [日历月份, 区域]
metrics: [月流水本期, 月流水同期, 月流水同比, 月店效本期, 月有效店数本期, 年累流水本期, 年累流水同比]
filters:
  - { name: 渠道品牌, values: [KOLON] }
  - { name: 店铺类型明细, values: [正价店, 折扣店] }
  - { name: 日历月份, values: ["2026-08"] }
```

执行：调用 MCP 工具 `export_report`，把上面 YAML 作为 `template_yaml` 字符串传入（见 SKILL.md）。

## 常用配方

- **区域月度概览**：rows `[日历月份, 区域]`，metrics `[月流水本期, 月流水同比, 月店效本期, 月有效店数本期, 年累流水同比]`（2026-08 实测：东北 1.39 亿/-5.7%，华东 5949 万/+30.5%）
- **店铺月度明细**：rows `[日历月份, 店铺名称]`，metrics `[月流水本期, 月流水同比, 月折扣本期, 月客单价本期, 月连带率本期]`
- **开关店追踪**：filters 加 `是否新开店（计算数量:1是,0否）: ["1"]`，metrics `[月流水本期, 月店效本期]`
- **客流表现**：rows `[区域]`，metrics `[月进店客流人次本期, 月进店率本期, 月成交率本期, 月客流人次小票数本期]`
- **多月对比**：`日历月份: ["2026-06", "2026-07", "2026-08"]`，rows `[日历月份]`

## 注意

- **空白区域行**：区域 `" "`（未分配）流水为空但店数/坪效可能有值，汇总时保留并标注
- **指标名是全称**：必须带 `{月|年累}` 前缀和 `{本期|同期|同比}` 后缀，如 `月流水本期`（写 `流水` 会报字段未找到）
- 状态筛选字段名**带括号说明**：`是否有效店本期（1是,0否）`、`是否新开店（计算数量:1是,0否）` 等，逐字复制
- **导出 CSV 恒为全量结果集**：`limit`/`offset` 对导出无效，可不写
- 拿不准字段名：Grep `templates/channel_monthly_kolon.reference.yaml`（全量 37+250 注释清单）
