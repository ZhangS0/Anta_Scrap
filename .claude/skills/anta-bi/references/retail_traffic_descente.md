# 报表指引：零售客流分析-迪桑特（retail_traffic_descente）

DESCENTE 品牌的客流专项报表。7 维度 × 11 度量（HAR 抓取基础字段），最细到「店 × 日 × 时段」颗粒。
特色：时段起止筛选（限制 10-23）、进店率计算、同期客流对比。
指标含义查 `metrics-glossary.md`（Grep，勿整读）。字段名以下方维度/度量清单为准（逐字一致），fdId 由 MCP 服务端按名解析。

## 特别说明（业务口径，来自用户提供的 HAR 注释）

1. **去重口径切换**：20250116 之后默认去重客流、之前默认非去重客流；客流人次 = 非去重客流
2. **闰年日期异常**：日区间自定义报表中 2025-02-28 对应的同期数据为 2 天（2024-02-28、2024-02-29），使用时请注意
3. **时段语义**：时段经过了+1 处理，即"时段=10"代表 9:00~10:00 之间的客流数
4. **时段限制**：客流数据限制 时段>=10 且 <=23

## 维度（7，按分类）

- **时间（1）**：日历日期
- **组织（3）**：区域、店铺编码、店铺名称
- **店铺属性（3）**：集合店属性、有效店标识、月同店标识

## 度量（11，按分类）

- **流水（6）**：流水、流水同期、流水同比、同店流水、同店流水同期、同店流水同比
- **客流（5）**：店外客流、进店客流、店外客流同期、进店客流同期、进店率

**注意**：当前字段目录来自 HAR 抓取的基础配置（非完整）。通过 MCP 实测导出后可补充完整目录（预计包含更多客流相关指标）。

## 模板格式与示例

```yaml
report: retail_traffic_descente
rows: [日历日期, 区域, 店铺名称]
metrics: [流水, 流水同期, 流水同比, 店外客流, 进店客流, 进店率]
filters:
  - { name: 区域, values: [迪桑特-华东区, 迪桑特-华北区] }
dynamic_params:
  起始小时: "10"
  终止小时: "23"
  开始日期-户外-R02: "2026-08-01"
  结束日期-户外-R02: "2026-08-07"
```

执行：调用 MCP 工具 `export_report`，把上面 YAML 作为 `template_yaml` 字符串传入（见 SKILL.md）。

## 常用配方

- **按日进店率趋势**：rows `[日历日期]`，metrics `[店外客流, 进店客流, 进店率]`
- **区域客流汇总**：rows `[区域]`，metrics `[店外客流, 进店客流, 进店率]`，日期取整周
- **店铺流水客流对比**：rows `[店铺名称]`，metrics `[流水, 流水同比, 店外客流, 进店客流]`

## 注意

- **时段限制**：起始小时和终止小时必须在 10-23 之间，否则无客流数据
- **日期筛选生效**：如需验证日期范围，临时把 rows 改成 `[日历日期]` 查看返回的日期列表
- **区域枚举**：区域筛选值必须带前缀"迪桑特-"（如"迪桑特-华东区"），用"华东"会返回空
- **导出 CSV 恒为全量结果集**：模板里的 `limit`/`offset` 只影响 BI 页面表格显示，对导出无效，可不写
- 拿不准字段名：以本页维度/度量清单为准，字段名需逐字一致
