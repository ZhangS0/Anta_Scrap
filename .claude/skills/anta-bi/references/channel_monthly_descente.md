# 报表指引：渠道运营分析-月报（channel_monthly_descente）

DESCENTE 品牌的渠道月报（店数/店效/坪效/面积专项）。39 维度 × 95 度量，最细到「店 × 月」颗粒。
适用：月度店效坪效分析、开关店追踪、改造前后对比、年累达成。
指标含义查本页下方分类说明或 `metrics-glossary.md`（Grep，勿整读）。字段名需逐字一致，fdId 由 MCP 服务端按名解析。
完整 fdId 清单在项目 `templates/channel_monthly_descente.reference.yaml`（Grep 定位，勿整读）。

## 与零售日报的区别

- **月颗粒**（非日），无 dynamic_params——**时间用筛选字段 `日历月份` 控制，格式 `YYYY-MM`**（如 `2026-08`），多月份传多个值
- **指标全部带「本期/同期」后缀**（如 `月流水本期`、`月流水同期`），无「同比」字段，需自行计算
- 聚焦渠道质量：店数（有效/保有/新开/改造/关闭）、店效、坪效、销售面积，**无客流/折扣/客单价类指标**

## 维度（39，按分类）

- **时间（2）**：日历月份、日历年份
- **组织（8）**：区域、办事处、省份、城市_映射、区县、零售经理、渠道品牌、品牌分类
- **店铺（13）**：店铺编码、店铺名称、店铺类型明细、店铺级别、门店性质、门店类型、经营类型、店型、店铺楼层、关店标记、关店日期、第一次开业时间、是否有效店本期（1是,0否）
- **改造（4）**：改造类型、最新改造开始日期、最新改造结束日期、集合店属性、集合店属性明细
- **商场（3）**：商场体系、商场代码、商场名称
- **品牌（3）**：品牌终端形象、财务所属品牌、顶特高、灯塔店、重点店铺
- **分析（3）**：同店类型、形象店龄、城市级别代码

- **流水（4）**：月流水本期、月流水同期、年累流水本期、年累流水同期
- **月度-店数（10）**：月有效店数、月保有店数、月新开店数、月改造店数、月关闭店数（各 本期+同期）
- **月度-店效（7）**：月店效本期、月店效同期、月店效同比、月保有店效本期、月新开店效本期、月改造店效本期、月改造店效同期、月改造店效同比
- **月度-面积（9）**：月保有店销售面积本期、月新开店销售面积本期、月改造店销售面积本期、月保有店平均面积本期、月新开店平均面积本期、月改造店平均面积本期、月保有店销售面积同期、月保有店平均面积同期、月保有店平均面积同比、月改造店平均面积同期、月改造店平均面积同比

- **年累-店数（8）**：年累保有店数、年累新开店数、年累改造店数、年累关闭店数（各 本期+同期）
- **年累-店效（8）**：年累店效本期、年累店效同比1、年累店效同期、年累保有店效本期、年累新开店效本期、年累改造店效本期、年累改造店效同期、年累改造店效同比、年累有效销售月数本期、年累有效销售月数同期

- **年累-坪效（10）**：年累坪效本期、年累保有坪效本期、年累新开坪效本期、年累改造坪效本期、年累坪效同期、年累坪效同比、年累改造坪效同期、年累改造坪效同比、年累改造坪效提升

## 模板格式与示例

```yaml
report: channel_monthly_descente
rows: [日历月份, 区域, 店铺名称]
metrics: [月流水本期, 月流水同期, 月店效本期, 月有效店数本期, 月保有店数本期]
filters:
  - { name: 渠道品牌, values: [DESCENTE] }
  - { name: 店铺类型明细, values: [正价店, 折扣店] }
  - { name: 日历月份, values: ["2026-08"] }
```

执行：调用 MCP 工具 `export_report`，把上面 YAML 作为 `template_yaml` 字符串传入（见 SKILL.md）。

## 常用配方

- **区域月度店效**：rows `[日历月份, 区域]`，metrics `[月流水本期, 月流水同期, 月店效本期, 月店效同期, 月有效店数本期]`
- **店铺开关店追踪**：rows `[日历月份, 店铺名称]`，filters 加 `是否新开店: [是]`，metrics `[月流水本期, 月有效店数本期]`
- **改造效果对比**：rows `[店铺名称]`，filters 加 `是否改造店: [是]`，metrics `[年累改造前店效, 年累改造后店效, 年累改造坪效提升]`
- **坪效分析**：rows `[区域]`，metrics `[月度坪效本期, 月度坪效同期, 月保有店平均面积本期, 月流水本期]`
- **多月对比**：`日历月份: ["2026-06", "2026-07", "2026-08"]`，rows `[日历月份]`

## 注意

- **同比需自行计算**：报表无同比字段（除月店效同比/年累店效同比1 等个别），用 `(本期-同期)/同期` 算
- **空白区域**：区域枚举含 `" "`（空格，未分配店铺），汇总时保留并标注
- **月店效口径**：月店效本期 = 月有效流水/月店铺有效销售月数（见指标说明 Excel）；店效为 0 且店数为 1 的店（如新开店当月）属正常
- **导出 CSV 恒为全量结果集**：`limit`/`offset` 对导出无效，可不写
- 拿不准字段名：Grep `templates/channel_monthly_descente.reference.yaml`（全量 39+95 注释清单）
