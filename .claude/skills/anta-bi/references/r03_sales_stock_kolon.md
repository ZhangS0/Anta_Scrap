# 报表指引：R03-任意时间段销存结构分析-KOLON（r03_sales_stock_kolon）

**可隆(KOLON)品牌**的销存结构报表。商品运营分析：最细到「店仓 × 货号 × 尺码/颜色」颗粒（SKU 级）。76 维度 × 74 度量。
适用：KOLON 商品结构分析（大类/中类/系列/货号）、库存健康（动销率/库销比/齐码率）、**SKC 四级组织口径**（门店/办事处/区域/全国）、**同期款对比**、售罄与采购报废。
指标定义见 `captures/商品运营分析-指标说明.xlsx`。字段名需逐字一致；完整清单在项目 `templates/r03_sales_stock_kolon.reference.yaml`（Grep 定位，勿整读）。

## 与迪桑特 R03（r03_sales_stock_descente）的区别

| 维度 | KOLON 版 | 迪桑特版 |
|---|---|---|
| **SKC 指标口径** | 按**组织层级**：门店库存SKC数 / 办事处库存SKC数 / 区域库存SKC数 / 全国库存SKC数（各含 库存/齐码/零售/进货 4 类） | 按商品/店铺类型：库存SKC数-鞋服（正价折扣）等变体 |
| **同期款指标** | ✅ 有：流水_同期款、销售数量_同期款、库存数量_同期款、货通系列_同期款 等 8 个 | ❌ 无 |
| **产品年季维度** | 本期产品年季 / 同期产品年季 / 本期产品年 / 同期产品年 / 同期款号 / 同期款吊牌价 | 产品年季 / 产品年 / 产品季 |
| **独有筛选** | 上市日期、产品备注 | 货号、商品品牌、店仓编码/名称 |
| **时间维度** | 周 / 月 / 日 / 日历年月 / 日历年周 / 日历年份（无 日历季度） | 日历日期/周数/月份/季度/年份 |
| 度量数 | 74 | 70 |

共同点：同期对比期**完全自定义**（同期开始/结束日期-户外）；配货季多选不传=查全部；SKU 级数据量大。

## 维度（76，按分类）

- **时间（7）**：日历日期、日历年月、日历年周、周、月、日、日历年份
- **商品（30+）**：货号、商品编码、尺码、颜色、款号、商品名称、商品品牌、大类、中类、小类、系列、子系列、产品季、**本期产品年季/年、同期产品年季/年**、**同期款号、同期款吊牌价**、性别、上下装、POP款、IMC类型、业务类型、设计国家、商品吊牌价格、上市日期/月、南区/北区/华南上市日期、首销日期-货号/款号、图片地址、**产品备注**
- **组织（10）**：区域、区域编码、办事处、省份、城市映射（注意：本表无下划线）、县区、城市等级、零售经理、销售主管/经理、渠道品牌、品牌大区、仪表盘维度
- **店仓（20+）**：店仓编码、店仓名称、店仓标识、店铺类型明细、门店性质、门店类型、店铺分级、店效分级、渠道分级、经营类型、商场代码/名称/体系、第一次开业日期、关店日期、最新改造类型/开始/结束日期、品牌终端形象、店铺楼层、集合店属性、集合店属性明细

## 度量（74，按分类）

- **销售（12）**：流水、流水同期、流水同比、销售数量、销售数量同期、销售数量同比、销售吊牌额、销售吊牌额同期、销售吊牌额同比、折扣、折扣同期、折扣同比
- **货通（6）**：货通销售流水/数量/吊牌金额 + 各同期
- **同期款（8）**：流水_同期款、销售数量_同期款、销售吊牌额_同期款、货通销售流水_同期款、货通销售数量_同期款、货通销售吊牌金额_同期款、库存数量_同期款、库存吊牌额_同期款
- **库存基础（10）**：库存数量（+同期/同比）、库存吊牌额（+同期/同比）、实物库存数量、实物库存金额、在途库存数量、在途库存金额、库存均深、库存吊牌均价
- **SKC 四级组织（16）**：{门店|办事处|区域|全国} × {库存SKC数、齐码SKC数、零售SKC数、进货SKC数}
- **库存健康（6）**：齐码率、齐码率（正价折扣）、动销率、动销率（只对货号去重）、月库销比、月库销比同期
- **期初/采购/报废（10）**：期初库存吊牌额（+同期）、采购入库数量/吊牌金额（+同期/同比）、报废数量/吊牌金额（+同期/同比）

## 筛选字段（12 个有选择器映射）

| 字段 | 常用值 |
|---|---|
| 渠道品牌 | KOLON（本报表为可隆专项） |
| 品牌大区 / 区域 / 办事处 / 店铺类型明细 | 常规枚举 |
| **性别 / 大类 / 中类 / 系列 / 子系列** | 商品筛选 |
| **上市日期 / 产品备注** | KOLON 版特色筛选 |

## 动态参数（最多 5 个；配货季不传即查全部）

| 参数名 | 类型 | 说明 |
|---|---|---|
| 开始日期-户外-R02 | DATE | 本期起始日 |
| 结束日期-户外-R02 | DATE | 本期截止日 |
| 同期开始日期-户外 | DATE | **对比期起始（可自定义）** |
| 同期结束日期-户外 | DATE | 对比期截止 |
| 户外_配货季(多选) | STRING | 如 `2026Q3,2026Q4`（逗号分隔多值） |

## 模板格式与示例

```yaml
report: r03_sales_stock_kolon
rows: [中类, 货号]
metrics: [流水, 流水同期, 销售数量, 库存数量, 动销率, 月库销比, 齐码率]
filters:
  - { name: 渠道品牌, values: [KOLON] }
dynamic_params:
  开始日期-户外-R02: "2026-08-14"
  结束日期-户外-R02: "2026-08-20"
  同期开始日期-户外: "2025-08-13"
  同期结束日期-户外: "2025-08-20"
```

执行：调用 MCP 工具 `export_report`，把上面 YAML 作为 `template_yaml` 字符串传入（见 SKILL.md）。

## 常用配方

- **中类销存结构**：rows `[中类]`，metrics `[流水, 流水同期, 销售数量, 库存数量, 动销率, 月库销比]`（2026-08-14~20 实测：软壳夹克 2848 万/+82%，长裤 1974 万）
- **货号级售罄/动销**：rows `[货号, 中类]`，metrics `[流水, 销售吊牌额, 库存吊牌额, 动销率, 门店库存SKC数]`
- **同期款对比**：rows `[系列]`，metrics `[流水, 流水_同期款, 销售数量, 销售数量_同期款]`（同款对比，排除款号结构变化影响）
- **区域 SKC 分布**：rows `[区域]`，metrics `[区域库存SKC数, 区域齐码SKC数, 区域零售SKC数, 区域进货SKC数]`
- **采购报废追踪**：rows `[大类]`，metrics `[采购入库数量, 采购入库数量同比, 报废数量, 报废吊牌金额]`

## 注意

- **数据量极大**（SKU 级），rows 一定要限定（中类/货号/单店仓）
- **配货季参数谨慎传**：排查"查出来是空"时先去掉它
- **字段名口径差异**（vs 迪桑特版/日报）：城市映射（无下划线）、`货通销售吊牌金额`（同期款系列里带「金额」）、周/月/日 是单字
- 状态筛选无（迪桑特版也没有），筛选就 12 个映射字段
- 导出 CSV 恒为全量结果集：`limit`/`offset` 对导出无效，可不写
- 拿不准字段名：Grep `templates/r03_sales_stock_kolon.reference.yaml`
