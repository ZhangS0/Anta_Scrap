# anta-bi 报告专员 Agent 使用说明

> 适用对象：已按 `INIT_PROMPT.md` 完成安装配置的 agent 及其使用者。安装引导找 INIT_PROMPT，
> 日常怎么用看本文。agent 被问「你能干什么」时也可直接展示本文。

## 一、这个 agent 能做什么（五类请求）

| 功能 | 说法示例 | 你会得到 |
|---|---|---|
| **查数** | 「查一下 KOLON 上周流水」「导出迪桑特 7 月店效」 | 数据表/摘要（不成报告） |
| **从 0 构建报告** | 「帮我做一份迪桑特 8 月流水达成报告」 | 完整分析报告（HTML/Markdown/Excel） |
| **修改/整合报告** | 「在上次报告里加客流章节」「把两份周报合成一份」 | 更新/合并后的报告 |
| **按 plan 重跑** | 「按上次的 plan 执行，日期改成 8/16–8/22」 | 同口径新批次报告（只确认变化项） |
| **新增可查报表** | 提供 HAR+查询参数：「把这个报表接进来」 | 新报表接入查询体系（维护操作） |

## 二、典型交互流程（构建报告为例）

```
需求讨论（目标/指标/时间/品牌/格式）
  → 计划确认：报告结构 + 格式约定（单位/高亮/排序）一次确认 ← 你拍板
  → 采集：BI 实时查询，给数据概览确认
  → 加工：中间结果/异常发现确认
  → 报告预览 ← 你提修改意见
  → 定稿 + 沉淀 plan（下次可直接重跑）
```

- **每个确认点 agent 都会先给你看再继续**，随时可以改需求。
- 重跑类任务只确认变化参数，过程不打扰（数据量/口径异常才主动报告）。

## 三、你需要提供什么

| 场景 | 必须给 | 可选给 |
|---|---|---|
| 查数 / 报告 | 工号（BI 账号）；密码仅**首次**，服务端记住后不再要 | 参考报表/历史数字（只用于核对，不作为数据源） |
| 构建报告 | 关注指标、时间范围、品牌、输出格式偏好 | 样例报告、口径说明 |
| 重跑 | 变化参数（日期/品牌/指标） | — |
| 新增报表 | 完整查询 HAR + 查询参数 | 指标说明文档 |

## 四、产物在哪

```
workspace/<报告名>_<报告id>/
├── templates/      查询模板（复用资产）
├── plan.md         工作流 plan（参数表，重跑的依据）
├── analysis.py     数据加工脚本
└── history/<run>/  每次生成的 CSV + 报告（run=日期-时分，只增不覆盖）
```

- 交付的报告文件在当次 run 目录里，agent 会给路径；历史批次可追溯、不会被覆盖。
- 「按 plan 重跑」就是改 plan 参数表里的值再执行，不用重新描述需求。

## 五、数据可信约定（重要）

- 报告中所有数据**一律来自实时查询**；你提供的参考数字只用于交叉核对（关键指标偏差超 ±5% 会提示差异，仍以查询结果为准）。
- 每个指标在进报告前都经过口径验证（字段是否存在、口径、时间范围限制），不可行的会当场沟通替代方案。

## 六、当前可查报表速查

| 报表 | 品牌 | 查什么 |
|---|---|---|
| 零售运营分析-日报 | 迪桑特 / 可隆 | 流水、目标达成、客流（迪桑特全）、试衣（可隆）、店效分级 |
| 渠道运营分析-月报 | 迪桑特 / 可隆 | 月度店数、店效、坪效、开关店、改造（按日历月份） |
| R03-任意时间段销存结构 | 迪桑特 / 可隆 | 商品/SKU 级销存：货号/中类/系列的流水、库存、动销率、库销比、齐码率 |

新增报表走「新增可查报表」流程（需完整查询 HAR）。

## 七、常见问题

| 现象 | 说明 / 怎么办 |
|---|---|
| 返回「需要密码」 | 该工号首次登录，补一次密码即可（服务端记住） |
| 报告里某指标缺列 | 部分报表（KOLON 系）不支持个别指标且不报错，agent 会自动换指标 |
| 查询等了半分钟 | 正常：BI 导出是异步任务，数秒~1 分钟 |
| agent 反问口径问题 | BI 字段口径差异（如「预算目标」vs「全月目标」），按业务实际回答 |
| 想重跑上次报告 | 说「按 plan 执行，改 XX」即可，不用重新描述 |

## 八、反馈与隐私

- agent 会在检查点（每次查询、报告交付、遇到问题）自动向服务器上报**结构化摘要**（报表/指标/成败/口径笔记），用于持续改进 skills 与字段指引。
- 上报内容不含密码、API key，也不含对话全文；密码只在首次登录使用一次。
- 报告内容只发给当前会话的你，不经 agent 外传。
